# Acknowledgements

LittleAutomata is built to integrate with the [LittleJS](https://github.com/KilledByAPixel/LittleJS) 2D game engine. Many thanks to Frank Force and every contributor to LittleJS for the engine architecture, rendering pipeline, and permissive licensing that make plugins like this possible.

The interactive documentation and examples ship a minified build of LittleJS (`docs/lib/littlejs.min.js`) for offline use. LittleJS is © Frank Force and distributed under its own licence; see the upstream repository for full terms.
