Left click: pour sand · Right click: explode

Basic Sandbox Walkthrough

Initialise the Engine

Call initGranularEngine() once during gameInit() to allocate the grid, register default materials, and prepare the renderer.

initGranularEngine({
  gridWidth: 512,
  gridHeight: 256,
  pixelsPerUnit: 16,
  originX: -16,
  originY: -8,
  subSteps: 1
});
Paint Starting Terrain

Use paintCircle() to stamp materials in world units. Material ID 2 is Stone and 3 is Sand.

paintCircle(0, -2, 6, 2); // Stone base
paintCircle(0, 4, 3, 3);  // Sand mound
Step and Render Each Frame

Advance the simulation in gameUpdate() and draw terrain in gameRenderPost().

function gameUpdate() {
  updateGranularEngine();
}

function gameRenderPost() {
  renderGranularEngine();
}
Mouse Painting and Explosions

Left click pours sand at the cursor; right click triggers a crater via createExplosion().

if (mouseIsDown(0)) {
  paintCircle(mousePos.x, mousePos.y, 0.5, 3);
}
if (mouseWasPressed(2)) {
  createExplosion(mousePos.x, mousePos.y, 2.0, 1.5);
}
