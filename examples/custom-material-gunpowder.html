Custom Material Walkthrough

Register a Custom Material

Call registerMaterial() after initGranularEngine() to add Gunpowder at id 9.

const GUNPOWDER_ID = registerMaterial({
  id: 9,
  name: 'Gunpowder',
  archetype: Archetype.FALLING_SOLID,
  density: 1300,
  friction: 0.6,
  flammability: 0.9,
  baseColours: [0xFF454545, 0xFF383838, 0xFF2D2D2D]
});
Register a Reaction Rule

Use registerReaction() so Fire touching Gunpowder yields more Fire with a 40-step lifetime.

registerReaction(
  MaterialId.FIRE,
  GUNPOWDER_ID,
  MaterialId.FIRE,
  MaterialId.FIRE,
  1.0,
  40
);
Paint Gunpowder and Fire

Left click deposits Gunpowder; right click places Fire to ignite the chain reaction.

if (mouseIsDown(0)) {
  paintCircle(mousePos.x, mousePos.y, 0.4, GUNPOWDER_ID);
}
if (mouseIsDown(2)) {
  paintCircle(mousePos.x, mousePos.y, 0.15, MaterialId.FIRE);
}
Why Initialisation Order Matters

Material and reaction registration mutates the active engine singleton, so both calls must happen inside gameInit() after the grid exists.

function gameInit() {
  initGranularEngine({ /* ... */ });
  GUNPOWDER_ID = registerMaterial({ /* ... */ });
  registerReaction(/* ... */);
}
